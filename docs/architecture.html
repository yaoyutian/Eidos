多模态大模型 · 技术蓝图

一条序列，一座大脑，三座感官塔

从零构建一个同时支持文本、图像、音频的 AI 大模型，不需要三套模型。 核心范式是：三座模态塔各自编码，一条投影桥把非文本特征翻译成「视觉 token」与「音频 token」， 再与文本 token 拼成同一条序列，交给一个 decoder-only LLM 统一自回归解码。 全文只维护一条 KV cache，训练与部署各只有一条路径。

1 条 KV cache 3 座编码塔 静态 token 预算 分阶段冻结训练 vLLM 原生可承载
总体架构

为什么是「早融合 + 单序列」

多模态融合有三条主流路线。对需要同时支持训练与部署的自建模型，早融合是唯一能把推理复杂度压到最低的选择。

维度早融合（本方案）Cross-Attn 旁路独立模型 + 工具调用
KV cache1 条，完全统一1 条 + 旁路状态多条，需编排
推理引擎vLLM / SGLang 原生支持需改引擎内核需多服务编排
视觉 token占用上下文预算不占主序列转文本后占用
长视频扩展token 线性增长可交叉注意力池化需先摘要
训练复杂度低（单条路径）中高（冻结分层训练）高（多模型对齐）
跨模态深度融合共享全部层仅隔层注入经文本中转，有损

序列组装

占位符静态展开：整套方案的关键约束

文本里的 <image> 不是「一个」token，而是在送入模型前展开成 256 个连续占位符；<audio> 每 30 秒展开成 25 个。模型靠掩码把特征原位替换回去。

为什么必须静态

形状静态——推理期 batch shape 恒定，可用 CUDA Graph 与连续批处理；掩码对齐——占位符数量必须精确等于特征数量，否则特征会错位到别的图片上；预算可预估——能提前算出上下文占用与显存。

上下文预算怎么算

每张图 = 256 token ≈ 200 个汉字的上下文；每 30 秒音频 = 25 token。10 图 + 1 分钟音频 ≈ 3050 token，已占 32K 上下文的 9.5%。视觉 token 数是延迟与效果的第一权衡旋钮。

视觉 token 数的四档取舍

64 · 激进压缩
省 75% 延迟
144 · 网格重采样
576→144
256 · 均衡（推荐）
2.2× 压缩
576 · 不压缩
细节最好

延迟以视觉塔前向 + 主干 prefill 估算。压缩率越高，OCR / 图表 / 密集文字类任务掉点越明显。

训练

四阶段递进，每阶段只解冻该解冻的部分

多模态训练最大的坑是「一上来全参微调，数据还没学会就先把基座冲垮」。正确做法是分阶段逐步解冻。

  1. STAGE 0 · 基座

    纯文本预训练（或直接复用开源基座）

    推荐直接用开源基座（如 Llama / Qwen / Mistral）。从零预训练 7B 需要约 15T token、数百张 A100 算力，是完全不同的工程量级——除非有数据与预算优势，否则不建议。

  2. STAGE 1 · 对齐

    只训投影器，冻结全部主干

    数据：595K 图文对（CC3M / LAION / COYO）。目标：把视觉特征翻译到文本 embedding 空间。LR 1e-3（比 LLM 高两个数量级），1 epoch。这一步参数量最小，收敛最快，是整个多模态训练的成败关键。

  3. STAGE 2 · 指令微调

    解冻 LLM + 投影器，冻结两座塔

    数据：多图对话、OCR、图表、数学视觉题。LR 分组——LLM 2e-5 / 投影器 2e-4 / 视觉塔 0（仍冻）。此时模型学会「按指令用图」，但还不懂声音。

  4. STAGE 3 · 全模态 SFT

    加入音频塔，解冻全部

    数据：语音识别、音频问答、音频描述，与图文数据混合采样。LR 全部降到 1e-5 量级，并可选 LoRA 防止灾难性遗忘。之后再接 DPO / RLHF 做偏好对齐。

工程决策

建之前必须定下来的事

应该做

  • 直接复用开源基座，把算力投在模态对齐上
  • 从 Stage 1 只训投影器开始，验证通路
  • 占位符数量与特征数量做强校验，错位立即报错
  • 投影输出加 LayerNorm，对齐文本 embedding 尺度
  • 视觉/音频塔保持冻结，让它成为稳定的「翻译源」
  • 训练与部署共用同一份 config.json，杜绝结构漂移

要避免

  • 一上来全参微调三座塔，数据没学会先把基座冲垮
  • 跨注意力旁路方案，除非明确要改 vLLM 内核
  • 投影器输出不做归一化，尺度失配导致训练不收敛
  • 视觉 token 无限增长，256 只是起点不是终点
  • 音频塔与 LLM 用同一个学习率，音频梯度会淹没语义
  • 训练配置与部署配置各写一份，半年后必然对不上
